# El Pollo Loco 🐔

A 2D jump-and-run game built with vanilla JavaScript and the HTML5 Canvas.
Run, jump, throw bottles and defeat the angry chickens — including the endboss!

🔗 **Live Demo:** [your-link.de](#)

![Screenshot](screenshot.png)

## 🎮 How to play
- **← / →** — move
- **Space** — jump
- **D** — throw bottle

## Features
- 🕹️ Object-oriented game engine (canvas rendering loop)
- 🐔 Enemies, collisions & an endboss fight
- 📊 Status bars for health, coins and bottles
- 🔊 Sound effects & music
- 📱 Responsive layout / touch controls
